How does it work?
  1. Count how often each character appears.
  2. Put the counts in a min-heap.
  3. Repeatedly merge the two rarest into one node. This builds the Huffman tree.
  4. Left branch = 0, right branch = 1. Frequent characters get short codes.
  5. Replace every character with its code and pack the bits into bytes.
  6. Save the tree inside the file so it can be decompressed later.
